# Cameracal Services Sensor Health Check – Beta

This is a static client-side beta build intended for limited testing.

Safety notes:
- No server-side upload is performed by this app.
- Image analysis runs locally in the user's browser.
- JPEG is the only supported file type in this beta build.
- The PDF report is generated locally in the browser using a print/save workflow.
- The Developer Demo option is for beta testing only and will be replaced by a real payment workflow before public launch.
- Do not upload confidential or sensitive images during testing.
