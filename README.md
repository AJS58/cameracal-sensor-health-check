# Cameracal Services Sensor Health Check – Tester Beta

This is the current tester-facing beta build.

## Privacy & image handling

- JPEG test images are processed locally in the browser.
- The app does not intentionally upload, store or transmit the original JPEG image.
- The app does not intentionally collect or transmit embedded GPS/EXIF metadata.
- Exported reports, annotated images and clean-preview files are only saved if the tester chooses to download/save them locally.
- Testers should avoid using personal or sensitive photographs.
- Recommended test images are plain sky, plain wall or white-screen dust-test images.

## Beta notes

- JPEG only.
- RAW files are not supported in this beta.
- The Developer Demo option is provided only for beta testing of PDF reports.
- Detection is indicative and continues to be refined.
